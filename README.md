# Well-Log Data Quality Assessment and Visualization

## Overview
This project uses Python to assess well-log data quality and visualize selected petrophysical logs. It demonstrates basic data inspection, quality checks, potential outlier identification and log visualization.

## Objectives
- Assess data completeness and consistency.
- Check for missing values, duplicate records, and duplicate measured-depth values.
- Examine potential outliers and values that may require further review.
- Visualize Gamma Ray (GR), Resistivity (RES), Bulk Density (RHOB), and Neutron Porosity (NPHI) logs against measured depth (MD).

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly Express
- Google Colab / Jupyter Notebook

This project focuses on data quality assessment and visualization. Identifying potential outliers does not automatically mean that the corresponding measurements are erroneous. Further geological and petrophysical review may be required before any values are modified or excluded.
